NATIVE DROPDOWN DEFECT
----------------------

Reported symptom:

The Riot server selector opened with a white native WebView2 popup while Aura's
option text remained white. Unselected servers were therefore invisible. The
same native-control mismatch could affect match filters, advisor roles, and the
Spotify device selector.

Fix:

- Declared `color-scheme: dark` at the application root and on every select.
- Gave every select an explicit dark fallback background and readable text.
- Gave normal options a #f8fafc foreground over #11111d.
- Gave disabled options a #94a3b8 foreground over #11111d.
- Gave selected options a white foreground over #4c1d95.
- Applied the rules globally instead of patching only the Riot server selector.
