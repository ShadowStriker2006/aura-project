DYNAMIC MAP CONTROL REPLAY
--------------------------

Implemented:

- Lazy GET /lol/match/v5/matches/{matchId}/timeline integration.
- Direct typed deserialization that skips unused heavyweight Timeline fields.
- Required metadata/info/frames validation and match-id verification.
- Single-flight timeline requests and a bounded three-match volatile LRU cache.
- A streaming 16 MiB Timeline response ceiling before typed JSON decoding.
- Compact positional/team/event JSON contract joined to cached Match-V5 detail.
- Interpolated champion movement with blue/red portrait borders.
- Curved estimated territorial-pressure frontier and Blue/Red percentage bar.
- Synced Kills, Gold, Turrets, and Game Clock header.
- Timed major-objective banners.
- Map Control Over Time Canvas graph with synchronized scrubber.
- Play/Pause, -15s, +15s, and 1x/4x/8x/16x playback controls.
- Collapse/profile/page/document lifecycle cleanup and 24 FPS active cap.
- Device pixel ratio capped at 1.5; no D3/framework dependency.
- Base-aware recall snapping, smooth normal travel, and missing-position carry-forward.
- Three-entry frontend LRU plus authoritative Match-V5 match-end duration.
- Summoner's Rift availability guard requiring positions from both teams.
- OCE Match-V5 routing corrected to Riot's SEA regional host.

The UI explicitly says Estimated Map Control. Riot Match-V5 Timeline does not
provide measured fog-of-war polygons or a complete guaranteed ward-position
stream. BUILDING_KILL and newer objective-specific event fields are parsed as
best-effort optional fields because Riot's formal event DTO does not guarantee
their complete observed payload.

LIVE-DATA / PUBLICATION LIMITS
------------------------------

1. A real recent match timeline still requires a valid, non-expired Riot API
   key and an account with accessible Match-V5 history. The local fixture and
   DTO tests do not substitute for a production-key live acceptance test.
2. Dynamic territorial pressure is currently calibrated only for Summoner's
   Rift map 11. Other maps return an explicit unavailable reason.
3. Riot Timeline positional frames are coarse and are interpolated. The view is
   a tactical replay, not a frame-perfect reconstruction.
4. Clean-user installer install, upgrade, and uninstall should be tested before
   broad distribution.
5. These local artifacts are not Authenticode-signed. A public installer must
   be signed and timestamped through the protected release workflow.
6. Riot development keys expire and must never be embedded in a public build.
