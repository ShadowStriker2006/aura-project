AURA 0.13.0 VALIDATION REPORT
=============================

Date: 2026-08-10
Platform: Windows x64 (MSVC), Tauri v2, WebView2


RESULT
------

PASS. Aura 0.13.0 compiled as an optimized 64-bit Windows application,
produced an NSIS installer, passed the complete deterministic Rust and
frontend suites, rendered the expanded dashboard and overlay in browser
fixtures, and completed bounded native launch smoke tests.

This result does not claim that Riot exposes every requested live metric.
Exact earned GPM, DPM, total team-gold lead, and XP progress remain visibly
Unavailable because the documented Live Client Data API does not provide the
necessary authoritative inputs.


IMPLEMENTED SCOPE
-----------------

- Kept get_summoner_profile (Summoner-V4) and get_league_entries (League-V4)
  as separate Rust functions, registered IPC commands, requests, caches, and
  frontend failure paths.
- Removed load_riot_id_prefs, save_riot_id_prefs, RiotIdPrefs, and every
  remaining reference to that volatile dead store.
- Routed frontend commands and dynamic Spotify/overlay/advisor actions through
  the validated IPC service rather than scattered raw invoke calls.
- Kept replay map assets offline and pinned through
  src/assets/maps/manifest.json and generated browser metadata. The live Data
  Dragon catalog version is display-only and never builds a local filename.
- Added the typed channels game:state-changed, live:game-tick,
  live:player-update, and draft:update.
- Reused one Live Client Data supervisor. During an active game it polls the
  bounded local endpoints once per second, refreshes objective/player detail
  every five seconds, and does not scan the process table at 1 Hz.
- Removed the duplicate legacy aura-objective-timers channel.
- Added exact Level, KDA, Current Gold, CS, CS/min, and derived KP percentage.
- Added explicitly estimated observable held value and observable value/minute
  from current cash plus the listed value/count of every held item. Both are
  availability- and provenance-gated.
- Kept earned GPM, DPM, team-gold delta, and XP progress Unavailable instead
  of presenting a zero or unrelated estimate as measured data.
- Expanded the main Match Command Center and the click-through overlay to ten
  low-cost metric cells plus objective timers.
- Sized the native overlay to 360x540 logical pixels and kept it non-focusable
  and mouse-click-through.
- Added a 2 MiB response cap, 500 ms local request timeout, finite-value
  normalization, three-failure recovery threshold, changed-only DOM updates,
  and listener/timer cleanup.

KNOWN RELEASE LIMITS
--------------------

1. A real League custom/normal match was not available. Endpoint accuracy,
   overlay behavior in exclusive/borderless modes, input latency, frame time,
   CPU, RAM, and network overhead still need acceptance testing on the intended
   low-spec target while League is running.
2. The exact 360x540 logical overlay and 760px main-page layouts were visually
   tested. Native 100%, 125%, 150%, and 200% DPI acceptance was not completed.
3. A clean installer install/upgrade/uninstall cycle was not run because that
   would mutate the user's installed application state. The NSIS package was
   successfully generated and version/hash inspected.
4. Local artifacts are intentionally unsigned test builds. A public release
   must use the documented signed CI workflow and a valid Authenticode
   certificate/timestamp.
5. Public Riot API distribution requires product registration and an approved
   server-side production-key design. Development keys expire and must never be
   embedded in a desktop binary.
6. Riot's documented Live Client Data fields do not provide the authoritative
   inputs for exact earned GPM, DPM, team-gold lead, or XP progress. Those wire
   fields remain contract-compatible but unavailable until a trustworthy data
   source is introduced.
