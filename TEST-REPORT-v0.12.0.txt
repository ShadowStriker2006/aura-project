AURA 0.12.0 VALIDATION REPORT
=============================

Date: 2026-08-09
Platform: Windows x64 (MSVC), Tauri v2, WebView2


RESULT
------

PASS. Aura 0.12.0 compiled, passed the complete deterministic Rust and
frontend suites, rendered the typed live-client HUD in the real application
page fixture at desktop and narrow widths, produced an optimized portable
executable and NSIS installer, and completed an eight-second native launch
smoke test without exiting early.

KNOWN RELEASE LIMITS
--------------------

1. A real League match acceptance test was not available in this deterministic
   build run. The 1 Hz local endpoints, event timing, CPU, and network overhead
   must be observed with League of Legends running on target hardware.
2. Riot's official Live Client Data API does not expose live champion damage
   totals or exact team total gold. The wire fields are retained for contract
   stability, but metricAvailability is false and the UI says Unavailable.
3. The local artifacts are intentionally unsigned test builds. A public release
   must use the documented GitHub signing flow and a valid Authenticode
   certificate/timestamp.
4. Public Riot API distribution still requires product registration and an
   approved server-side production-key design; never embed a production key in
   the desktop binary.
