=============================

Validation date: 2026-08-09
Platform: Windows x64 (MSVC)
Scope: ranked-profile failure isolation, IPC integrity, pinned replay map
assets, release build, portable startup, and packaging.

RESULT
------

PASS. Aura 0.11.1 compiled, passed the complete deterministic test suite,
produced a portable Windows executable and NSIS installer, and started
successfully in a five-second smoke test.

STRUCTURAL FINDINGS AND RESOLUTION
----------------------------------

1. get_league_entries

The command had previously been folded into get_summoner_profile. That was not
a missing-symbol compile problem, but it created an all-or-nothing failure:
a League-V4 error could hide valid Summoner-V4 level/icon data and prevent the
Match-V5 history stage from running.

Resolution:
- get_summoner_profile now fetches only Summoner-V4 icon and level.
- get_league_entries is restored as a separate League-V4 command.
- Level/icon, rank, mastery, and recent matches start independently after
  identity resolution and have separate success/error presentation.
- Rank results use a two-minute, per-identity volatile RAM cache.
- Concurrent rank callers share one OnceCell in-flight request.
- API-key and identity changes atomically invalidate cached and active rank
  state so an old response cannot repopulate a new profile.

2. Apparently unused Tauri commands

The advisor draft/live/post, Spotify play/pause/previous/skip, and overlay
show/hide commands are live. Their command strings are deliberately selected
from fixed frontend dispatch tables/button handlers, so a direct static invoke
grep does not reveal them. get_champion_details is a direct live call.

The only genuinely orphaned command was load_riot_id_prefs. Its matching save
command wrote a RAM-only value that no caller ever read. The complete dead
preference path was removed: backend state, DTO, save/load commands, handler
registrations, frontend save call, obsolete persist options, and fixture stub.

A new IPC contract test now verifies every registered Tauri command against
both direct and reviewed hard-coded dynamic frontend dispatch. It also rejects
frontend command names that do not have a registered handler.

3. Replay map asset versioning

The bundled minimaps must remain pinned and must not follow the live Data
Dragon catalog. Using the live version to construct a packaged filename would
be the actual 404 risk.

Resolution:
- Added src/assets/maps/manifest.json as the canonical pinned registry.
- Runtime filename/version metadata and the asset README are generated from
  the manifest.
- scripts/VERIFY-MAP-ASSETS.ps1 checks schema, exact filenames, byte counts,
  SHA-256 digests, PNG signatures, source URL convention, exact PNG set, and
  generated metadata/documentation synchronization.
- The verifier runs before the local publisher cache check and in release CI.
- The live Data Dragon version is display-only advisory metadata.
- Image load/decode failure visibly reports a neutral coordinate grid while
  champion movement and calibrated pressure rendering remain available.

KNOWN RELEASE BOUNDARIES
------------------------

- These local artifacts are intentionally unsigned. A public installer still
  requires the documented Authenticode certificate/signing workflow.
- Clean install, upgrade, and uninstall were not executed in this patch test;
  the generated NSIS package itself was verified by Tauri.
- Live Riot and Spotify acceptance depends on the user's current accounts,
  League Client state, Spotify Premium/device eligibility, and a non-expired
  Riot key. No plaintext credentials were read or logged during this test.
- Bundled terrain remains a visual reference, not authoritative brush,
  pathing, fog-of-war, recall, or vision geometry.
